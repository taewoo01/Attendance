# Attendance
대학생 창업팀이 함께 쓰는 내부 협업 웹 서비스. 

주요 기능 11가지: 
① QR코드 스캔 출석 인증 
② DAY/NIGHT/FULL TIME 상주 시간 등록(시작~종료 시각 포함) 
③ 팀 전체 공개 개인 일정 캘린더 
④ 수업·알바 등 고정 시간표 등록(학기 종료 시 수동 초기화) 
⑤ 실적 관리(제목/날짜/담당자/내용/첨부 + 선택적 매출 지표) 
⑥ 댓글·리액션 가능한 아이디어 자유게시판 
⑦ 외부(투자자 등)에도 공개 가능한 회사 소개 페이지 
⑧ 이름/역할/연락처 중심 명함형 팀원 소개 
⑨ 프로젝트별 폴더 구조의 자료실 
⑩ 액션아이템(담당자/기한) 포함 회의록 
⑪ 서술+체크리스트 혼합형 데일리 업무 정리
